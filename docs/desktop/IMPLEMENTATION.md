## Notes / divergences
Divergences from `openspec/changes/archive/2026-10-16-desktop-shell/design.md` (none changes behaviour that a spec
scenario describes):
- `main/paths.js` does the portable-path redirects as import-time side effects and is the first
  import of `main/main.js` (ESM hoists imports, so statements after them would be too late). Chromium's
  profile is `data\profile`; `cache.json`, `device.json` and the smoke port file are in `data\`.
- Extra pure modules: `lib/args.js`, `lib/partition.js`, `lib/shortcuts.js`, `lib/ipc-args.js`,
  `lib/viewmodel.js`, `lib/icon.js`. Extra main modules: `main/smoke.js`, `main/smoke-phases.js`.
- IPC: `show(itemId, paneId?, {split})` also performs the split (open-resolution, the blocked and Edge
  rules and the layout edit are one path); `contextMenu(kind, id)` covers items, workspaces and groups;
  added `setOverlay`, `confirm`, `pickProgram`, `onCommand`, `onShortcut`. `saveDevice` takes only
  `edgeProfile` and `autostart` from the UI.
- Native site views paint above the DOM, so dialogs, item drags and divider drags detach all views
  (`setOverlay`); the delete confirmation is a native message box (the D8 prompt it used to share with is gone, D119).
  Toasts therefore sit beside the item list (a toast at the window's bottom centre could be hidden behind a page).
- Popups: `did-create-window` is too late to set a UA (the first navigation has started), so the UA is
  also applied through `app 'web-contents-created'` (adoptPopup), the DevTools emulation override and a
  per-session `onBeforeSendHeaders` rewrite. This applies only to items with a non-default preset; a
  default-preset popup is untouched (D65: the default UA passed Google sign-in in the spike).
- Packaging: the launcher stages the app and core into `.cache/stage` (same relative layout as the repo,
  tests left out), reuses the Electron binary in `node_modules` (`electronDist`), generates the icon,
  and writes `.cache/package.json` (`"type": "commonjs"`) so tools electron-builder downloads into the
  cache are not treated as ES modules by the repo's `"type": "module"`.
- The smoke run writes to its own folder (`%TEMP%\fruitery-smoke-data`) with a local HTTP server and stubs
  for Edge, the default browser and native dialogs; flags `--smoke-step=2`, `--shots=<dir>`,
  `--data-dir=<dir>`, `--no-local-seed`, `--hidden`.
- `reorder('item', parentId, …)`: `parentId` is the target group id or null (an item can join a group of
  its own workspace while being reordered); removing a workspace cascades to its groups and items, and
  the last live workspace cannot be removed; `upsert` answers `{ok, ids}` or `{errors}`.
- Cookie opt-out is host-suffix based: a cookie scoped to a parent domain of an opted-out host is still
  made persistent (documented risk).
- Ticks used the local clock until `desktop-sync` (D41, D69); since that change they go through the Worker once a
  PC is connected, and the local clock remains only for a PC that is not configured. There is no taskbar badge, no
  auto-update, no UI toggle for close-to-tray (stored, default on).
- Not automated: the tray menu, autostart, close-to-tray with a real hide, Google sign-in, the End-task
  test and the real Edge launch; they are in [general/manual-checks.md](general/manual-checks.md).
