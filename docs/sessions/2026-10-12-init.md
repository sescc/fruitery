## 2. Decisions
See the `CLAUDE.md` decision log (D1–D45). Key kept/discarded:

| Decision | Verdict | Why |
|---|---|---|
| Ferdium | discarded | workspace UX, no reorder, Google login blocked, reload on switch |
| Rambox Basic / Pro | discarded / not pursued | Basic lacks workspaces, 2 custom apps, 1 PC; Pro is paid + installer-only |
| Edge Workspaces | discarded | no checklist, no in-app panes |
| Own Electron app + Cloudflare Worker/D1/PWA | kept | only option meeting all requirements |
| Preact/Vite/Hono | discarded | same shipped size; extra tooling; user wants minimal deps |
| Single portable exe / installer | discarded | `dir` target with `<exeDir>\data` instead |
| Manual wrangler deploy | discarded | Actions deploy + manual migrations (several PCs) |
| Cookie re-save on quit | discarded | unreliable on reboot; convert on set instead |
