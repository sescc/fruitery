# Fruitery

Repo folder: `ProductivityUnifier`.

Fruitery is one interface for the user's daily web tools:
- a portable Electron desktop app (`apps/desktop`) with workspaces and split panes;
- a Cloudflare Worker + D1 + PWA (`apps/web`) that syncs everything and serves the Android checklist;
- shared pure logic in `packages/core`.

Architecture model: `docs/architecture-map.md` → `docs/<component>/ARCHITECTURE.md`.
Work state: `openspec/`. Session handoffs: `docs/sessions/`.

## Conventions
- Shipped defaults are neutral (timezone UTC); personal values live in git-ignored `config/*.local.json`. Nothing identifying is committed (D53).
- Plain JavaScript ES modules with JSDoc + `// @ts-check`. No TypeScript build, bundler or UI framework.
- Only devDependencies allowed: `electron`, `electron-builder`, `wrangler`. Nothing is installed globally.
- Tests: `node --test` with `node:test` + `node:assert/strict`; D1 is emulated with `node:sqlite`. Node ≥ 24.
- Desktop data lives only in `<exeDir>\data` (portable); nothing goes in `%APPDATA%`/`%LOCALAPPDATA%`.
- The user does all `git add/commit/push`. Claude never does.
- Opus orchestrates and reviews; Sonnet subagents write all source and tests.
